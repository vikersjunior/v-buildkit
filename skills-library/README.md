# Your Claude Workforce — Skills Pack

**42 original skills** (7 departments, 6 each) + **28 sourced community design skills**, all ready to install.

## Structure

```
01-developers/          6 skills — build discipline, live docs, MCP tooling, browser QA, cross-session memory
02-design/               6 original + external-community/ (28 sourced skills from 5 open-source repos)
03-marketing/            6 skills — SEO, programmatic SEO, AI-answer-engine SEO, CRO, ad creative, persuasion psychology
04-social-content/       6 skills — platform-native social, copywriting, content strategy, video, pillar content, email
05-finance/              6 skills — DCF, 3-statement model, LBO, comps, pricing, pitch deck
06-operations/           6 skills — SOPs, postmortems, business cases, launch runbooks, internal comms, live-formula xlsx
07-legal/                6 skills — contract review, NDA triage, legal risk flagging, compliance, tracked-changes docx, SQL pulls
```

Full department README: see each folder. Design department's sourced-skill attribution and usage guide: `02-design/external-community/README.md`.

## Which agents can actually use these

See `WHICH-AGENTS-CAN-USE-THESE.md` in this folder for the full breakdown — short version: Claude Code, Claude in Cowork/Desktop, and (via copy-paste of the SKILL.md body into a system/project prompt) most other agent harnesses. Cursor, Codex CLI, Gemini CLI, GitHub Copilot, Grok Build, OpenCode, and several others now support the same "Agent Skills" folder convention natively — several of the sourced design skills ship pre-built installers for exactly those tools.

## Install

Drop any department folder — or the whole pack — into your Claude Code / Cowork skills directory. For the sourced design skills specifically, most support a one-line installer; see `02-design/external-community/README.md`.
