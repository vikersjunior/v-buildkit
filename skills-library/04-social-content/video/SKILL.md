# Video — Scripting & Production Planning

For scripting and structuring video content — the plan a videographer or editor would work from, not the editing itself.

## Short-form (TikTok/Reels/Shorts) structure

1. **Hook — first 1-2 seconds.** Must create a reason to keep watching before any context is given. A slow build-up loses most of the audience before the point lands.
2. **Payoff, fast.** Get to the actual value/point within the first 5-8 seconds — don't make the viewer wait through preamble.
3. **One idea per video.** Trying to cover multiple points in 30-60 seconds means none land clearly.
4. **Visual/pacing cue every 2-3 seconds** — a cut, a text overlay, a scene change — static long takes lose retention on short-form platforms specifically.
5. **Explicit CTA at the end**, even if simple ("follow for more", "link in bio") — don't assume it's implied.

## Explainer/longer-form structure

1. Open with the specific problem/question being answered — orient the viewer before diving into explanation.
2. Structure the body as a clear sequence (numbered steps, chronological, or problem→solution) — viewers should always know where they are in the explanation.
3. Use visuals to carry information the narration alone can't (diagrams, on-screen text for key numbers/terms) — don't rely purely on spoken narration for anything precise.
4. Close with a clear recap or explicit next action.

## Script format for handoff

Write in two columns: what's shown on screen, what's said/narrated — so a video editor can work from it directly without guessing pacing intent.

## Common failure

Writing the script like an essay to be read aloud rather than a script built for the visual medium — video scripts should be shorter, more fragmented, and paced for spoken delivery, not written prose.
