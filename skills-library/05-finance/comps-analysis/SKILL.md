# Comps Analysis — Comparable Company Valuation

Relative valuation via benchmarking against a peer set, rather than intrinsic (DCF-style) valuation.

## Step 1: Build a genuinely comparable peer set

Screen on: same or adjacent industry/business model, similar growth profile, similar margin structure, similar size (revenue/EBITDA scale — comparing a pre-revenue startup to a mature public company distorts the multiple badly). A peer set of 5-10 genuinely comparable companies beats a larger set padded with weak comparables — quality of the comp set matters more than quantity.

## Step 2: Choose the right multiple(s) for the business type

- **EV/Revenue** — for high-growth, pre-profitability companies where EBITDA isn't yet meaningful.
- **EV/EBITDA** — the most common general-purpose multiple, works once a company has stabilized, positive operating cash flow.
- **P/E** — relevant for mature, profitable companies, less useful for capital-structure comparisons across companies with different leverage.
- Sector-specific multiples where standard (e.g. price/AUM for asset managers, EV/subscriber for subscription businesses) — match the multiple to what the industry actually uses to talk about value.

## Step 3: Calculate and normalize

Pull each peer's current multiple, but adjust for one-off items (non-recurring charges, unusual working capital swings) before comparing — raw reported figures without normalization produce a misleading multiple.

## Step 4: Apply to the target

Apply the peer set's median (more robust to outliers than mean) multiple to the target's corresponding metric, producing an implied valuation range — present a range (e.g. 25th-75th percentile of the peer set), not a single point estimate, since comp-based valuation is inherently a range exercise.

## Common errors

- Including peers that are superficially similar but fundamentally different in growth/risk profile just to pad the sample size.
- Using stale multiples without checking for recent market moves that would date the analysis.
- Presenting a single multiple as precise valuation rather than a supporting range alongside other methods (DCF, precedent transactions).
