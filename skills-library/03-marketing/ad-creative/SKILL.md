# Ad Creative — Scaled Ad Variation Generation

For generating genuinely differentiated ad variants for testing, not 20 near-identical restatements of the same line.

## Vary on real axes, not surface wording

Generate variations across distinct dimensions so tests actually isolate what's working:
1. **Angle** — pain-point-led, benefit-led, social-proof-led, curiosity-led, urgency-led. These are functionally different ads, not just reworded copy.
2. **Format constraint** — platform-appropriate length and tone (Meta feed vs. TikTok native-style vs. Google search ad character limits) — don't write one ad and reformat it, write for the platform's actual consumption context.
3. **Audience framing** — same product, different entry point per audience segment (a first-time buyer angle vs. a "switch from competitor" angle).
4. **CTA variant** — direct ("Buy now") vs. low-commitment ("Learn more") vs. curiosity-driven — CTA choice measurably shifts click quality, not just click volume.

## Per-ad structure

- **Hook (first line)** — must work standalone since it's often the only part seen before a scroll-past decision.
- **Body** — one clear benefit or proof point, not a feature list.
- **CTA** — matched to actual funnel stage (cold audience → low-commitment CTA; retargeting → direct CTA).

## Output format for testing

Group variants by which single variable changed, so a test result is attributable. Label each variant with its hypothesis ("testing urgency framing vs. social-proof framing, same offer") — untagged variant soup makes post-test analysis useless.

## Compliance guardrail

Flag any claim that would need substantiation (specific numeric results, "#1", medical/financial claims) before it ships — ad platforms and regulators both penalize unsubstantiated claims, and it's cheaper to catch pre-launch.
